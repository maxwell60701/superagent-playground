# superagent-playground

Private test repository for Codex SuperAgent tasks sent through Feishu.

## Run checks

Requires Node.js 22 or newer. No dependencies need installing.

```sh
npm test
```

`src/greeting.mjs` contains a small greeting function with tests.

## First task to try

Mention the bot in the configured Feishu test group:

> Give greeting an optional language parameter supporting English and Chinese, preserve the existing default behavior, add tests, and open a pull request. Do not merge it.

Review the resulting pull request and checks before merging manually.
